# 🚀 Sobre o Projeto (ERP System)

## 📌 Visão Geral

Este projeto consiste no desenvolvimento de um **Sistema de Gestão Empresarial (ERP)** modular, escalável e de alto desempenho, projetado para centralizar, automatizar e otimizar processos de negócios corporativos.

O sistema está sendo construído do zero com foco em **Domain-Driven Design (DDD)**, manutenibilidade e aplicação das melhores práticas de Engenharia de Software (Clean Code, princípios SOLID e Padrões de Projeto GoF).

---

## 🛠️ Status do Desenvolvimento

O projeto encontra-se na fase de **modelagem do domínio e estruturação da arquitetura**.

Atualmente, o foco está em:

* Mapeamento das regras de negócio centrais.
* Implementação e validação do modelo de domínio (entidades, objetos de valor, agregados e interfaces de repositório).
* Estruturação do modelo relacional e preparação da camada de persistência.

---

## 🏗️ Arquitetura & Tecnologias

### **Back-end & Linguagem**

* **C# / .NET:** Escolhido pela robustez, forte tipagem, performance e ecossistema maduro para aplicações corporativas de grande porte.

### **Persistência de Dados**

* **Microsoft SQL Server:** Banco de dados relacional (RDBMS) de nível empresarial para garantir consistência ACID, integridade referencial e alta performance em consultas complexas.
* **ORM:** Entity Framework Core *(planejado para mapeamento objeto-relacional)*.

### **Infraestrutura & Cloud (Planejamento)**

* **Hospedagem Cloud:** Planejado para implantação em ambiente **AWS** (Amazon Web Services) ou **Microsoft Azure**, utilizando containers (Docker) e esteiras de CI/CD para deployment automatizado, alta disponibilidade e escalabilidade vertical/horizontal.

---

## 📋 Funcionalidades em Escopo (Em Modelagem)

* **Módulo Administrativo & Segurança:** Autenticação, autorização (RBAC) e gestão de usuários/perfis.
* **Módulo Comercial & Vendas:** Gestão de clientes, orçamentos e pedidos.
* **Módulo de Suprimentos & Estoque:** Controle de produtos, movimentações e fornecedores.
* **Módulo Financeiro:** Controle de contas a pagar, contas a receber e fluxo de caixa.
